# 地点导航：place → 地图

> 方向：通知里已经抽出了地点，让它能点开去地图。
>
> ✅ **本文档 §三 已于 2026-10-15 落地**：`web/src/mapUrl.ts` +
> `ItemCard.tsx` 的「🗺 在地图中查看」（渲染在卡片按钮**之外**——HTML
> 不允许嵌套交互元素）。§三 的三个边界都有测试钉着（空 place 不渲染、
> 非地名照常渲染、空格必须 `encodeURIComponent`）。
>
> ⚠️ 本文档的核心是**如实分级**：实测数据说这件事**只有约 30% 成立**，
> 而不是全部。把这个数字写进文档，比写"支持地点导航"有用。

## 二、为什么不做「精确点位」

校园内部建筑在**高德/百度都没有独立 POI 点位**：

- 「实验楼 305」→ 地图上只会搜到「XX大学」这个大门
- 「食堂二楼」→ 同上

**所以做不了"导航到 305 教室"。** 能做的是：

```
place 文本 → 地图搜索 URL → 用户自己看
```

⚠️ 这个诚实的定位很重要：**它是"帮你在百度里搜一下"，不是"导航"。**
叫「导航」会过度承诺，用户点了发现到位的是大学门口，会觉得是 bug。

**建议按钮文案**：`在地图中查看` 而不是 `导航`。

## 三、实现：一个纯函数 + 一个按钮

### 后端：不加端点

地图链接**完全由 `place` 文本决定**，不需要服务器参与。
在前端算即可 —— 省一次请求，也省得后端操心 URL 编码。

### 前端：`web/src/mapUrl.ts`（新文件，约 30 行）

```ts
/**
 * place 文本 → 地图搜索 URL。
 *
 * ⚠️ 只做**搜索链接**，不做导航 —— 校园内部建筑在公开地图上没有点位
 * （见 docs/design/地点导航.md §二）。按钮文案相应是「在地图中查看」。
 */
export function mapSearchUrl(place: string, provider: 'amap' | 'baidu'): string | null {
  const q = place.trim();
  if (!q) return null;
  // ⚠️ 必须 encodeURIComponent：地点名里有空格（「实验楼 305」），
  // 直接拼进 URL 会被截断成「实验楼」。
  const enc = encodeURIComponent(q);
  return provider === 'amap'
    ? `https://uri.amap.com/search?keyword=${enc}`
    : `https://map.baidu.com/search?querytype=s&wd=${enc}`;
}
```

### ⚠️ 三个必须处理的边界

| 情况 | 处理 | 为什么 |
|---|---|---|
| `place` 为空 | 不渲染按钮 | 375 条里 255 条没有 place —— 渲染一个空按钮是噪声 |
| `place` 不是地名（`老地方`） | **照常渲染** | 前端**判断不了**"是不是地名"。硬做启发式（长度、黑名单）必然误伤，而错的判据比没有判据更糟 |
| 地点名里有空格 | `encodeURIComponent` | 「实验楼 305」不编码会被截成「实验楼」——**搜索到完全不同的地方**且用户不知道 |

⚠️ 第二条是刻意的：**不自作聪明**。用户点「老地方」搜不到，
他自己知道那不是地名；而如果前端猜错了把「图书馆」也判成非地名，
那才是真损失。

## 四、可选增强（不做也不影响）

| 增强 | 成本 | 价值 |
|---|---|---|
| 记住用户偏好哪个地图（高德/百度） | 低（存 localStorage） | 中 |
| 从 `place` 里剥掉楼层（「实验楼 305」→「实验楼」） | 低（正则） | **可能有害** —— 剥掉「305」反而丢了信息 |
| 自动定位到用户所在城市 | 中（要定位权限） | 低（校园场景城市是确定的） |

⚠️ 第二条**不建议做**：搜「实验楼 305」时，地图厂商自己会做模糊匹配
（搜不到精确的就退到「实验楼」）。我们剥一层反而是**替它做了个更差的决定**。

---

## 五、这一项在材料里怎么讲

**别写成"地点导航"**（那会过度承诺）。建议的写法：

> 条目自动抽取地点信息（实测覆盖率 **32%**），并可一键在地图中查看。
> ⚠️ 校园内部建筑在公开地图上无独立点位，故本功能定位为
> **「在公开地图中搜索该地点」**，而非室内导航。

这段话的好处：**它主动划出了边界**。评委看到的是"这个团队知道自己做到哪一步"，
而这正是初赛"创新性"要的判断力。
